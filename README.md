# 网页视频下载器

Windows 本地视频下载工具，用于验证“粘贴网页链接、选择真实可用画质、下载并检查文件”的完整流程。目标网站为央视网、好看视频、抖音、B站和优酷。网站列入目标范围不代表其全部视频都可下载。

## 使用

1. 解压整个发布文件夹，双击 `WebVideoDownloaderPrototype.exe`。保留同目录的运行文件，不要只复制主程序。
2. 粘贴视频网页地址或包含链接的分享文案，解析可用画质。
3. 选择画质和保存目录，开始下载。默认保存到 Windows 当前用户的“下载”文件夹下的 `WebVideoDownloader` 子目录。
4. 等待下载与校验完成，再打开文件所在文件夹。下载期间可以取消任务。
5. 需要登录时打开“账号与扫码登录”，选择对应网站，在官方登录页面完成扫码、短信或其他验证，再使用当前会话重新解析视频。

## 账号与画质

- 各网站使用独立会话。默认仅在本次运行中使用；“记住登录”默认关闭。
- 启用记住登录后，会话使用 Windows DPAPI 在本机加密保存；可以在账号管理中清除。
- “会话已导入”只表示取得会话数据。账号是否有效、是否有会员资格、能取得哪些画质，需要实际解析视频确认。
- 已有会员权益不等于任意会员视频都能导出。DRM、地域限制、验证码、过期链接和网站接口变化都可能影响结果。
- 分辨率描述视频文件尺寸。平台提供的 1080p 文件也可能使用原本模糊的监控素材。

## 从源码运行

在项目目录使用 PowerShell：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe prepare_tools.py
.\.venv\Scripts\python.exe main.py
```

`tools` 存放随包运行的 FFmpeg、ffprobe、Node.js 及所需 DLL；`vendor` 存放央视专用格式处理依赖。仅安装 Python 包不能替代这些文件。

构建 Windows 发布目录：

```powershell
.\build.ps1
```

构建完成后运行 `dist\WebVideoDownloaderPrototype\WebVideoDownloaderPrototype.exe`。
