# Web Video Downloader v0.11.0

## 更新缓存管理（#22）

- 大文件缓存默认放在程序根目录的 `update` 文件夹，不再持续新增到 C 盘 LocalAppData；更新状态小文件仍保留原位置。
- 右上角“设置”→“更新缓存：目录与清理”可更换目录、查看新旧位置占用及手动清理。不可写或目录有未知内容时明确提示，不静默退回 C 盘。
- 启动后及每小时后台维护闲置缓存：最多保留 7 天、闲置总量默认 1 GiB，优先清理最旧项。正在更新和待安装内容受保护，可能临时超限。
- 新版安装成功且实际运行版本核对通过后，清理对应更新包及展开文件；准备失败时清理未完成的展开目录，保留续传下载包。
- 保留旧缓存位置记录，按需复用同一更新包；安全识别历史缓存。无法识别、损坏引用和额外未知文件保守保留，界面显示未识别数量。
- 缓存不纳入发布包、程序完整性基线和安装备份。更新准备、安装助手及清理互斥；独立修复/回退工具同样遵循缓存设置。

## 使用与升级

可下载完整 Windows x64 包到新目录解压使用，保留整个目录。首次从旧客户端在线升级到本版，下载和准备仍由旧版执行，因此这一次仍可能使用旧的 C 盘目录；安装本版后的更新才使用新策略。

本版不会整体迁移账户、设置或下载任务数据，也没有改造旧程序目录同级备份的整体策略。清理工具只处理已识别且没有被引用的缓存；未知内容不会强删。
