# Web Video Downloader v0.9.0

## 更新中心（#17）
- 更新说明渲染 Markdown，支持标题、列表、粗体、表格和链接；显示目标版本、发布日期、更新方式及下载大小。
- 默认启动后延迟 15 秒检查，运行与托盘期间每 4 小时检查；设置可关闭或调整间隔。自动检测只提示，不下载安装。
- 更新入口显示红点和新版版本；支持稍后提醒与忽略当前版本，后续新版仍正常提示。

## 增量、安全安装与历史回退
- 发布最近 3 个基线到当前版本的文件增量。符合条件时优先增量；运行库、数据兼容或发行策略要求时使用全量。
- 缺少增量或本地文件被修改时，先确认再改用全量；保留下载续传、自动重试、大小及 SHA-256 校验。
- 安装前组装校验完整程序，按程序文件清单备份和替换，失败恢复旧版；账号、下载文件与任务记录保留。
- 提供最近 3 个兼容稳定历史版，手动确认回退；优先有效本地备份，否则完整包。回退前备份设置，并暂时忽略刚离开的版本。
- 新增独立“修复与回退.cmd”，不依赖主程序和 Qt，支持离线恢复及在线历史版本修复。维护脚本保留在程序目录 .maintenance 中，回退到旧版后仍可使用。
- 检查更新与下载任务可并行查看，安装不会自动中断任务。失败检查静默记录并退避，保留已知更新提示。

## 首次升级
**0.8.0 及以前版本首次升级本版仍需下载完整包；以后才启用增量更新。**

程序正常时使用“检查更新”。主程序无法打开时先退出所有下载器进程，再运行程序目录的“修复与回退.cmd”；首次启动前的备用入口为 `_internal\recovery.cmd`。
