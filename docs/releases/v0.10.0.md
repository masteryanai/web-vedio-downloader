# Web Video Downloader v0.10.0

## 全局媒体下载限速（#2）

- 设置中增加“限制媒体下载总速度”，默认不限速，可填写 0.01～102400 MiB/s。
- 多个下载任务、音视频组件及分片共享同一个总带宽预算，不会按任务数叠加上限。
- 保存后立即影响正在下载及后续开始、恢复的任务，无需暂停或重新解析；重启保留设置。
- 接入 HTTP 断点续传、yt-dlp 原生 HTTP/HLS/DASH、央视分片和抖音图文图片/配乐下载。
- 限速等待可暂停、取消；任务列表及悬浮窗继续展示实际下载速度。软件更新、本地合并与校验不受媒体限速影响。

限速作用于应用读取的媒体数据，允许短暂网络缓冲波动；不是操作系统级流量整形，不保证任务均分或跑满上限。需要外部网络下载器的特殊媒体格式会明确提示暂不支持，避免绕过共享预算；本地 FFmpeg 处理仍正常使用。

## 使用

打开右上角“设置”，勾选限速并输入 MiB/s，点击保存。取消勾选并保存即可恢复不限速。1 MiB/s = 1024 KiB/s。

可下载完整 Windows x64 包到新目录解压运行；保留整个目录。本版不改动更新器备份策略，不会由开发过程覆盖现用客户端目录。
