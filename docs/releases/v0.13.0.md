# Web Video Downloader v0.13.0

## 独立安装进度窗口（#25）

- 保留下载速度、更新说明和“立即更新并重启／稍后安装”流程。确认安装后，先打开独立更新窗口，窗口就绪才退出主程序；交接失败时原程序继续运行，待安装包保留。
- 安装窗口展示校验、等待退出、备份、替换、再次校验、启动确认与清理等真实阶段，显示本阶段文件数量、百分比和耗时；等待阶段显示活动进度，不虚构总百分比。
- 安装中可最小化，不允许中途关闭或取消。只有新主窗口可见、进程和目标版本核对通过后才自动关闭安装窗口。
- 安装失败时保留窗口，显示失败步骤、原程序恢复结果，并提供安装日志和独立修复入口；启动确认失败会尝试恢复原程序。
- 记录阶段耗时及文件复用统计。备份时同步计算校验值，复用该结果判断未变化文件，减少重复读取；保留切换前后的完整性校验与原有回退保护。
- 安装状态和日志继续保存在程序的受管理 `update` 目录，持久更新记录位于 `data/updates`，不新增 C 盘备用目录。

## 首次升级说明

**从 v0.12.0 或更早客户端升级本版时，安装交接仍由旧客户端执行，不会提前出现本版新增窗口。** 安装本版后发起的在线更新或独立恢复才使用新窗口。

优先提供兼容的文件增量更新；运行库或兼容策略不满足时按现有规则使用完整包。历史旧版本不支持新的启动回执时，核对其可见主窗口与 EXE 产品版本。下载的媒体和便携数据不进入程序文件备份。
