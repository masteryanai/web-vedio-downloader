# Web Video Downloader v0.9.2

## 更新中心优化（#19）
- 独立进度卡突出当前阶段、文件计数、百分比；下载速度、下载量与预计剩余时间独立展示。
- 打开窗口只读取更新信息并估算包方式，不再扫描全部程序文件；点击下载时检查本地基线。
- 合并重复扫描：客户端准备阶段本地基线检查一次、完整目标检查一次；保留下载包 SHA-256，以及安装器切换前后的独立校验。
- 复制、解压和校验都有阶段进度，下载完成不会被误表示为“版本已更新”。

## 用户确认后更新并重启
- 完整准备后询问“立即更新并重启 / 稍后安装”，未经确认不退出应用。
- 选择稍后或关闭窗口保留已准备的包，入口改为“更新并重启应用”；重新打开不重复下载。
- 重启旧程序后可恢复仍有效的待安装计划；再次确认安装时刷新 PID 并核对归属及元数据。
- 有任务时保留待安装状态，不强行打断；后台检查不会覆盖该状态。
- 安装后在新进程核对实际运行版本并提示结果，失败保留原版与恢复入口。

## 首次使用新流程
**从 0.9.1 升级本版这一次仍使用旧更新界面；新确认流程在安装 0.9.2 后生效。**

沿用增量、续传、历史回退、独立修复和单实例行为。用户原有本地测试目录与运行程序不直接替换。
