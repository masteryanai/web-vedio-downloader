# Web Video Downloader v0.16.0

## 影片库恢复与迁移（#35、#36）

- 存储库自带作品、季、选集、稳定原网页来源、封面和本季设置。重新添加目录可预览恢复，不重新下载或移动影片。
- 当前资料、最近3份有效历史和独立来源清单分层恢复。来源清单需要联网核对并确认；失败保留只读记录。未知版本格式不会被覆盖。
- 支持原库搬家和独立副本。整库迁移先预览范围与大小，暂停任务，复制校验后再更新位置、清理未变化原件；字幕与附带文件一同迁移，库外引用保持原位。
- 未完成任务恢复为待继续。来源、权限或缓存不能安全验证时停止并保留旧片段，不静默从零覆盖。
- 只读、离线或其他实例占用时保留记录；视频完成但恢复资料写入失败时持续提示并提供重试。解除挂载保留视频和恢复资料。
- 程序索引损坏时可保留原件重建，再重新添加各库；不会猜测已经彻底丢失的影片身份。

## 构建和升级保护

- 开发构建改用专用 `build/release-output`，不清空旧 `dist` 或实际使用目录。构建、打包及安装管理清单拒绝混入用户资料和媒体。
- 元数据只备份小规模记录，不复制整套程序或影片作为库备份。不新增 C 盘存储回退。
- 安装回退备份只保存将被替换或删除的程序文件，未变化的大文件不再重复复制；离线回退时与当前未变文件组合并逐文件校验，兼容旧完整备份。
- 本版数据兼容版本为4，从旧版采用完整包；不允许在线回退到不兼容旧索引的版本。

## 使用

从“管理 → 存储库与播放器”操作“添加 / 恢复库”“迁移整个库”“重试保存 / 来源恢复”。详见影片库使用说明。

恢复后的非空缓存目前仅好看视频 HTTP 下载路径支持验证续传；其他下载引擎会明确停止，旧片段保留，需按取消确认流程处理后重新下载。网页下架、登录失效及磁盘损坏仍可能阻止恢复。

本版继续提供 Steam 风格 UI 供整体验收，#27 保持打开，发布不代表用户已验收。
