# Web Video Downloader v0.15.0

## Steam 界面重构（#27）

- 主窗口改为双层深色导航、可调整宽度的紧凑侧栏和底部状态栏；支持标题区拖动、双击最大化/还原与边缘缩放。
- 影片库采用最近入库陈列架与 2:3 封面网格，支持名称排序、分类、长标题提示、悬停与选中状态；空库保留完整操作入口。
- 季详情使用大图与主要动作栏，保留逐集播放、逐季播放确认、来源切换、选集分页与批量下载。
- 下载页全宽显示真实速度曲线、当前/峰值，任务使用封面宽行、简洁副信息和右侧快捷操作。原有全选、批量暂停/继续/取消/删除及完整路径搜索仍可用。
- 设置与存储空间使用分类侧栏；空间条区分本库已登记文件逻辑大小、其他占用与可用空间。只读取登记路径，不扫描整盘；离线与未知大小明确标注。
- 现有下载引擎、便携数据目录、账号、图文保存、限速、托盘、悬浮框及更新/回退流程保留。
- 修复大合集压力测试发现的 Windows 任务记录读写冲突（#33），以及后台线程清理尚未结束便报告空闲的退出竞态（#34）。

## 升级与验收

本版延续数据兼容版本 3。更新器根据客户端版本、文件校验和运行库兼容性自动选择增量或完整包，不要求迁移影片文件。

本次发布供用户整体验收；#27 在用户明确认可前保持打开。原版 Steam 截图仅作为开发参考，比较截图中的测试封面和演示文件不随程序发布，不代表真实影片、真实下载或可播放媒体。

首次使用仍须解压完整文件夹运行 `WebVideoDownloader.exe`。不要把新包覆盖到正在运行的程序目录。
