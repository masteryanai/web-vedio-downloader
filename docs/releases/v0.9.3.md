# Web Video Downloader v0.9.3

## 紧凑悬浮窗（#16）
- 展开尺寸缩为 160×60，宽度减半，移除“本轮下载概况”标题及下方统计行。
- 保留每 3 秒轮播：整体速度 → 整体进度 → 各实际下载中任务的速度。
- 当前页的数值位于进度条上方；整体页显示整体进度条，任务页显示对应任务进度。
- 长任务名省略显示，悬停查看完整名称；长速度数值适配宽度，保留单位。
- 任务结束、暂停或进入处理阶段后，移除对应速度页；不显示排队任务的历史速度。
- 靠边收起同步缩为 24×48，保留拖动、双击主界面、右键菜单、透明度和多屏定位。

本版不调整更新器备份策略。可下载完整包到新目录体验；安装本版不会由开发过程替换用户现用目录。
