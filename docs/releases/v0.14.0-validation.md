## 环境与边界

Windows C/S 客户端在本机开发、构建与原生验证。所有写入及下载样本使用仓库的隔离 scratch 目录或独立临时数据目录；未停止、覆盖用户现用的 `D:\Project\tools\WebVideoDownloader`，也未读取现用客户端的账号进行测试。

## 发布及兼容

新库任务包含选集关联与首次执行时解析画质策略，旧版无法正确恢复其未解析任务，数据兼容版本升为3。本次依既定策略提供约307.5MiB完整包，并禁止跨兼容版本直接回退；媒体与既有备份不因此删除。后续兼容构建仍按发布策略生成增量。

运行库和原生依赖未主动升级；首版不加入内置播放器、第三方影视封面搜索、浅色主题、观看进度追踪或自动连播。未完成任务先完成或取消再迁移，避免悄悄遗弃续传缓存。
