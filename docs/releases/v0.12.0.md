# Web Video Downloader v0.12.0

## 完整便携数据模式（#24）

- 设置、Windows 加密账号会话、任务记录、日志、适配记录和更新状态统一保存到 **程序根目录的 `data`**；更新包及准备文件仍放在 `update`，不静默回落 C 盘。
- 首次启动在后台迁移旧数据并逐文件校验。缺失旧更新目录或整个旧目录均正常；已下载的视频、图片和配乐以及任务输出路径不搬动、不改写。
- 校验通过后清理已迁移原件；已有目标文件不被覆盖，差异另存冲突副本。取消、空间/复制错误或源数据变化时保护原数据；未知旧更新文件保留，失效安装记录归档。
- 数据目录不可写或存在无法确认归属的内容时明确提示使用独立可写程序目录。记住的登录继续使用当前 Windows 用户 DPAPI 加密，更换电脑或 Windows 用户可能需要重新登录。
- Windows 用户级内存锁保持跨程序目录的单实例唤起，不需要在 C 盘留下实例锁文件。首次切换请先退出旧版；旧版仍运行时会优先唤起旧窗口。
- 独立修复和更新状态使用便携路径；`data` 和 `update` 不进入 Git、发行包、程序完整性基线或程序备份。

## 升级与回退边界

本次数据兼容版本升为 **2**。旧版不识别便携数据布局，不能直接跨布局回退，以免账号和任务不可见；旧备份不因此删除。首次从旧布局升级使用完整包，后续同布局版本仍可按兼容策略增量更新和回退。

从旧客户端在线升级这一次仍由旧版下载和准备；新版启动后执行迁移。也可下载完整 Windows x64 包解压到新目录，**先退出旧版再启动新版**。

以后将完整包换到新目录时，请把现有 **`data` 文件夹一并带上**，否则新目录会被视作独立的新安装。默认 `update` 及受管理更新引用可以跟随完整程序目录移动，媒体输出路径仍由用户指定。
