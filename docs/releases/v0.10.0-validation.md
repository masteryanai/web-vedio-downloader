# v0.10.0 全局媒体限速验证（#2）

- Windows 客户端在本机开发、构建和验证；没有覆盖 D:\Project\tools\WebVideoDownloader 现用目录。
- 配置默认不限速，单位 MiB/s，范围 0.01～102400；布尔值、字符串、负数、非有限数及越界值被拒绝，已有设置兼容。设置变更在写入成功后通知共享预算。
