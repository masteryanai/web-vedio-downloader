# Web Video Downloader v0.9.1

## 修复重复启动（#18）
- 同一用户数据目录只保留一个主窗口与托盘；再次运行唤起原窗口并退出新启动进程。
- 支持恢复托盘隐藏、最小化窗口，尽力将窗口带到前台；不会覆盖原有链接、解析结果或下载任务。
- 原子进程锁处理同时启动，异常退出后可重新启动；已有进程无响应时明确提示，拒绝额外打开实例。
- 命令行操作与后台故障监测保持独立，不被误判成重复 GUI。
- 沿用增量更新、定时检查、历史回退与独立修复。

## 升级提示
0.9.0 用户可使用增量升级。旧版没有单实例协议，首次切换请先正常退出多余旧窗口；托盘菜单中的“退出”才会完全退出程序。不会强制结束用户的旧版进程或打断下载任务。
