# v0.17.0 预览版：管理版与轻量下载器

本次同时提供影片管理版、轻量基础包、轻量离线完整包。两款产品分别解压到独立目录，设置、账号会话、任务和更新均独立；可同时运行，各自保持单实例。不要把两个产品覆盖解压到同一个文件夹。

- **影片管理版**：保留影片库、季/选集管理、已有视频导入、封面、播放及库恢复迁移。
- **轻量基础包**：默认打开下载任务，使用普通保存目录，不建立影片库。需要账号网页验证或抖音解析时，先说明浏览器组件用途、大小，经确认下载并校验到本程序目录。
- **轻量离线完整包**：预带上述组件，不需要首次另行下载。AGE 的站点验证仍使用本机已有 Chrome / Edge；离线完整包不代表无需访问视频网站或具备本机浏览器。

添加下载改为“粘贴/解析 → 选择内容”。画质和目录沿用最近选择，已有季保持原库归属；部分加入失败时保留内容及原因，成功项继续后台下载。关闭选择窗口不取消已入队任务。

剪贴板识别默认开启，只在启动/返回前台检查适配链接；多链接先选择，遇验证由用户显式打开。只保存有界链接指纹，可在设置关闭/清除记录，不自动开始下载。

完整性校验继续使用 FFmpeg 全片解码，耗时取决于片长、编码和硬件。任务展示实际校验时长、百分比及耗时；取消后保留文件为待校验，继续时核对本地文件，不重复解析或下载。缺失/变化会提示，不静默覆盖。

界面沿用深色桌面风格，更新中心移除浅色状态卡和最新版0%误导，添加入口采用可缩放图标，高级来源合并选项折叠，支持减少动画。

此版仍为预览。测试和发布验证记录见 [开发与验证记录](../qa/0.17.0-progress.md)；#27 总体验收须由用户完成，不能把自动测试通过作为验收通过。
