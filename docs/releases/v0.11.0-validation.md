# v0.11.0 更新缓存管理验证（#22）

- 已按用户确认采用程序根目录 `update` 默认目录、可配置路径、7 天 / 1 GiB 闲置缓存规则与手动清理。大文件缓存与原用户数据目录内的小型状态分离。
- `update_cache` 统一位置解析、归属记录、历史位置、引用保护、容量/期限淘汰及缓存复用。路径切换先验证归属和可写性，不能覆盖非空未知目录；存在待安装计划时保留原路径。
- 正在准备、安装、维护时通过进程内门锁及跨进程文件锁互斥。新安装器和独立恢复工具使用同一互斥；待安装记录在准备完成、释放缓存锁和通知 Qt 之前写入，避免交接间隙误删。
- 成功结果须与当前运行版本、安装目录相符才清理对应大文件；仅保留诊断和恢复使用的小型结果/计划。确认结果时锁尚未释放，则后台维护再次处理。失败准备清理本次展开目录，下载包保留续传。
- 默认、旧位置及自选目录只处理已识别的缓存。对活跃 PID、待安装/安装/恢复引用、损坏状态、未知内容及目录联接保守保护；未知文件单独显示，不宣称清理所有历史残留。
- 新缓存不进入程序清单、发布包或按清单进行的程序备份；程序清单生成仅遍历受管理程序根，不扫描 `update` 内的完整准备程序。
- `python -m unittest discover -s tests -v` 完整回归 **120 项通过**。新增 17 项缓存/界面用例，覆盖默认/自选位置、错误回滚、期限/容量、已确认清理、待安装保护、活跃进程、跨进程安装锁、旧缓存识别/复用、未知文件保留、链接拒绝、成功启动清理及后台 UI 生命周期。
- Windows PowerShell 安装/恢复协议套件 **16 项通过**，使用小型独立程序文件夹：验证安装、失败回滚、默认/自选缓存下的离线独立恢复、更新程序并发锁及待安装恢复；没有对用户真实程序进行完整安装或额外全量备份。
- 全部测试和 GUI 验证使用独立用户数据/临时安装目录；没有覆盖 `D:\Project\tools\WebVideoDownloader` 现用客户端，没有执行真实旧缓存批量清理。本版不改造旧程序目录同级备份整体策略。
- 首次从旧客户端升级仍由旧更新器下载和准备；新缓存策略在安装本版后生效。建议可直接下载完整包到新目录体验。
- 干净构建后，从最终 EXE 档案核对缓存、更新、待安装、启动确认、调度、设置、版本和清单模块，均与当前源码编译对象一致；随包安装/恢复 PowerShell 脚本也与源码哈希一致。
- 最终 v0.11.0 EXE 在独立临时用户数据目录实际启动，通过 Windows UI Automation 打开“更新缓存”窗口，捕获检查默认程序根目录 `update`、目录选择/恢复默认/应用、占用与清理说明及按钮完整显示；程序正常退出。
