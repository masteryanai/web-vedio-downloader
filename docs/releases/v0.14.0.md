# Web Video Downloader v0.14.0

## 影片库与 Steam 风格界面（#26，关联 #3 / #6 / #21）

- 默认首页改为影片库。影片库、季详情与下载任务在主窗口内切换；深灰蓝界面、封面卡片、详情横幅和贯穿底部的下载状态条。
- 添加影片弹窗集中完成链接解析、季归属、存储库、画质、选集与入队。每一季独立入库，单部影片和抖音图文独立管理。
- 多磁盘自定义存储库；新下载同季集中保存。支持读取旧下载记录、扫描所选文件夹或选择文件后预览入库，原文件不移动、不重命名；可确认对应到已有季与选集。
- AGE 支持作品详情页和单集播放页的按线路批量识别；B站支持番剧媒体页、季/选集页、合集及分P识别。其他已适配站保留单个作品下载，不宣称具备合集列举能力。
- 默认只勾选未下载集，检查本地文件；画质不足时可降到最高较低档，并提供严格跳过模式。保留并行、暂停、续传、限速与全片校验。
- 大合集按50集分页、可搜索；来源映射使用按需编辑，批量任务后台准备、分批进入队列，避免上千控件和文件写入阻塞界面。
- 网站来源与选集标识用于识别重复内容；跨网站归季需确认映射，可按明确集号生成待核对建议，未匹配集需明确选择新增。不静默跨源切换或覆盖视频。
- 不同播放线路分别保留来源身份，切换线路同样需核对选集对应，避免把URL序号误当集号。取消大批任务准备后，迟到的后台结果不会重新入队；已准备但未入队的任务保留为可继续记录。重启后仍正确显示待继续/失败数量。
- 外部播放器使用系统默认或用户指定的EXE；播放前确认，“不再提示”仅对当前季/独立作品生效。图文保留原图ZIP和配乐视频两种保存方式。
- 原站大小封面获取、站点占位及本地图片/图片链接手动替换；不自动搜索第三方影视资料站。
- 逐季手动刷新、可选1～168小时定时检查新集，只提示、不自动下载；默认关闭。检查失败保留已有内容。
- 移除库记录与删除媒体分开；外部文件不默认参与删除/迁移。受管理成品迁移先复制并逐文件SHA-256校验，再切换索引、清理原件；未完成任务须先完成或取消，保护续传缓存。
- 下载任务保留复选、搜索及批量操作，新增短期速度趋势图。全部下载完成提示3秒后恢复空闲；其他工作、暂停/失败状态分别展示。悬浮框透明四角、单层圆角，保留轮播、靠边收起及托盘行为。
- 设置支持滚动，主窗口适应屏幕可用区域及高DPI；独立安装窗口同步深色视觉并继续独立工作。

## 验证与升级说明

用户提供的AGE详情页实际列出9集；B站媒体页实际列出1,283个选集。各选前两集进行真实下载，四个样本均通过全片校验：AGE为1920×1080，B站匿名可用画质为640×480，验证了自动降档；不代表所有选集或会员画质都无需登录。

便携索引和封面保存在程序 `data/library`，软件更新缓存仍在 `update`，视频在所选存储库或导入原位置。首版不含浅色主题、内置播放器、观看进度同步或自动连播。

本版新增影片库关联与逐集延迟画质任务，数据兼容版本升为 **3**。旧版不能正确恢复这类待下载任务，因此本次按既定兼容策略提供完整升级包，并限制直接回退到旧兼容版本；不会自动删除旧媒体或旧备份。后续兼容版本继续按策略优先增量。

从v0.13.0在线升级可使用独立安装进度窗口；也可下载完整包解压。手工更换程序目录时，请保留并一并带上原 `data` 文件夹。
