# 影片库使用方法

## 首次升级

v0.14.0 使用完整包升级，安装器仍会验证文件并展示独立进度。若手动解压到新位置，先退出旧程序，并将原 `data` 文件夹一并带上；账号、任务和索引都在其中。视频仍在原保存位置。

## 设置存储库

打开“账号与设置 → 存储库与播放器”，添加专用媒体目录，例如 `D:\影视库` 或 `E:\动漫库`。也可从添加影片弹窗管理存储库。不同季可使用不同存储库，本季新增下载集中保存。

播放器留空使用系统默认；也可选择已有播放器的 EXE。不需要在下载器内安装另一个播放器。

## 添加合集并下载

1. 点击“添加影片”，粘贴播放链接、详情页或分享文案，点击解析。
2. AGE 支持 `/detail/作品编号` 与 `/play/作品编号/线路/选集`；B站支持番剧媒体页、季/选集页、合集与分P。抖音按原有流程打开官方窗口，需要时自行扫码或完成访问验证。
3. 检测到合集后核对作品与季名。没有可靠季信息时需填写或选择已有季，不把线路编号当作季；未分季的长期合集可自行使用明确的归属名。
4. 选择存储库和画质偏好。默认1080P优先，不足时使用最高较低档；严格模式则跳过没有该画质的选集，并在任务中说明。
5. 默认只勾选未下载集，可全选未下载、全不选或手动选择，点击“加入库并下载”。没有选集被勾选时只入库。
6. 下载任务在主窗口内管理。大合集后台准备任务、逐批入队；详情每页50集，可查询和翻页。批量操作继续以复选项为准。

AGE 的不同线路可能缺集或包含特别篇，不能只按 URL 序号互相对齐。已有季需要增加其他线路/网站来源时，在添加弹窗选择“确认合并到”，核对集号匹配建议，未匹配项可明确选择新增，然后确认。来源选择失败不会自动换到另一个来源。

## 播放与图文

进入季详情，已下载且文件存在的选集提供播放入口。默认确认后调用外部播放器；勾选“播放本季其他选集时不再提示”仅对当前季生效，可从“管理此季”恢复确认。

图文独立入库。原图保存为 ZIP，可打开所在文件夹；配乐视频可播放。如需另存其他画质或另一种图文方式，使用选集的“··· → 另存其他画质／图文方式”，已有文件不会覆盖。

## 导入旧视频

点击“账号与设置 → 导入已有视频”。可以读取旧下载记录、扫描选定的具体文件夹或选择文件。勾选要导入的内容，修正作品、季和选集名后确认。

已有对应季时可选择“归入已有”，核对每个文件的选集对应关系；明确选择新增才能建立额外选集。所有导入文件原位引用，不自动移动或重命名，也不自动扫描整盘。

## 整理、删除与离线

- “移除本季库记录”保留视频文件。
- 删除本工具下载的文件是单独操作，列出路径后确认；外部导入文件不默认参与删除。
- 本季存在未完成任务时，先完成或取消，再移除库记录或迁移，避免遗弃续传缓存。
- 迁移在选择目标存储库后，复制并逐文件校验，成功才切换索引并清理原件；外部文件保持原位置。
- 磁盘离线和文件缺失分开提示，不会因离线清空记录。文件重新定位可从选集“···”操作。

## 封面与新集

封面优先来自原站，缺失时站点占位。使用“管理此季”手动更换本地图片或填写图片链接，也可刷新选集与封面。

定时检查新集默认关闭，可按季开启并配置1～168小时间隔；软件运行时执行检查，只提示新集，不自动下载。关闭程序后不运行后台服务；登录失效或网络错误时保留已有资料。

全部下载完成后保留3秒完成提示，再恢复空闲；暂停、失败和仍在处理的任务会分别显示。历史记录、库记录和视频不会因实时状态复位而清除。
