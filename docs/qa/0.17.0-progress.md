## 已有证据及边界

- 早期整套 281 项通过；之后新增测试的一次整套 282 项发现大合集访问冲突，不能将该次称为通过。
- 大合集降低 GC 阈值的循环：修复前 3 次中 2 次 Windows 访问冲突，当前线程均在工作线程 GC；禁用自动 GC 对照 3/3 通过。
- 现由 GuiCollector 在 Qt 主线程定时执行分代回收，未永久关闭回收；同一原始循环 3/3 通过。测试还核实循环引用在主线程释放。
- Qt 要求 GUI 类只在主线程使用和销毁，参见 [Qt Threads and QObjects](https://doc.qt.io/qt-6.8/threads-qobject.html)。当前修复的因果依据来自上述本地对照，最终仍须整套及冻结运行回归。
- 真实 FFmpeg 小媒体取消、保留、禁止重新解析后继续校验已验证；待校验断点经库复制/恢复仍指向新库并可验证。
- 已有受控解析数据的真实 Qt 截图：管理版 100/125/150/200%，轻量版 100/200%。不将这些截图当成真实站点成功下载证据。
- 第一轮轻量基础 EXE 启动成功；缺少组件的浏览器探测明确失败。组件发现合法 Qt QML Components 目录误拒问题已修正。最终组件渲染仍待冻结验证。
