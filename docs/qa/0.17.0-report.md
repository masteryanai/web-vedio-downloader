# 0.17.0 预览版测试报告

总体验收 #27 保持打开；本报告是工程验证，不能代替用户验收。关联 #37、#38。

## 发布范围

| 产品包 | 体积（近似） | 用途 |
|---|---:|---|
| 管理版完整包 | 308 MiB | 影片库、季/选集、本地播放入口、库恢复迁移和下载 |
| 轻量基础包 | 168 MiB | 普通目录下载与任务管理；需要时确认下载网页组件 |
| 轻量离线完整包 | 308 MiB | 预带网页组件；AGE 仍需要本机 Chrome/Edge |
| 独立网页组件 | 149 MiB | 本版本固定 SHA-256 的组件，不是独立客户端 |
| 管理版 0.16.0→0.17.0 增量 | 10.4 MiB | 基线匹配时使用；不满足条件则完整更新 |

本次客户端和安装器依赖 Windows/Win32，因此在本机验证；家庭 Linux 仅用于发布文件中转。

两款分别安装，不共享设置、账号会话、任务、更新和单实例身份。轻量版不要求先入库。所有大文件仍在程序目录，组件成功安装后清理已验证 ZIP；相同内容的组件跨应用版本复用，避免按每个补丁版本复制一份运行库。

## 自动与真实运行验证

- 最终完整回归290项通过（201秒）；两款最终冻结构建和基础包入口/模块/资源一致性校验通过。
- 两款冻结构建通过 main 入口、59 个项目模块及安装资源与当前源码一致性校验。
- 真实 FFmpeg 生成小媒体，取消完整性校验后保留本地文件；禁止网络解析/重下载后继续校验成功。文件改变时拒绝继续并保留文件。
- 待校验断点经库复制/恢复后指向新库，可验证同一文件。清理缓存失败不会把已经发布的成品误报为待校验。
- 剪贴板默认/关闭、跨重启指纹、多个链接取消、弹窗暂缓、返回前台和显式验证有专项测试；不自动下载、不保存整段剪贴板。
- 大合集曾复现工作线程 GC 访问冲突及一次短生命周期 Qt 后台对象创建处的访问冲突。保留界面线程定时回收；纯 I/O/图片后台工作改为普通线程＋固定 GUI 信号入口，回调只在 GUI 线程执行并等待线程实际结束后才报告空闲。原始大合集压力循环连续10/10通过。
- 网页组件验证覆盖路径越界、损坏、取消、外来产品、已安装文件变化、后台校验期间心跳和关闭后迟到成功；不会静默覆盖损坏组件。
- 两款最终EXE并行运行、各自重复启动均返回0且原实例继续运行；轻量版实际用户互斥锁验证通过，管理版使用隔离资料避免影响用户旧版。空闲8秒单次工作集：管理版156.1MiB、轻量版77.4MiB；仅为本机空库/无浏览器页面的样本，不代表下载峰值或跨机器性能。
- 在全新隔离基础包安装正式网页组件后，真实冻结 EXE 的浏览器本地页与任务页均退出0，截图可见；未出现界面无响应诊断。组件补齐沙箱子进程的 DLL 依赖闭包，保留浏览器沙箱。
- 真实隔离安装器从 0.16.0 升至 0.17.0，新窗口可见并核对版本，更新窗口自动关闭（本机最终样本48.6秒）；影片、字幕、库记录、本季播放偏好和用户哨兵文件保留。备份 13,170,790 字节（约12.6 MiB），3255 个未变化文件没有重复备份。
- 用户提供的 AGE 与 B 站合集链接实际解析均退出0；这证明本轮解析路径可用，不代表已下载整季、所有账号权限或所有源均可用。

## 限制与复核

- 仍是预览版，没有宣称达到 Steam 的百分比相似度或用户已验收；#27不关闭。
- 本地播放沿用外部播放器；站点登录/验证码、会员权限由用户正常完成，不保证所有网站/账号情况。
- 基础包首次需要网页组件时要联网确认下载；没有额外更新服务器，使用GitHub Release轮询与资产校验。
- 工具运行测试使用隔离目录；用户正在运行的旧版未被强行退出或覆盖。升级时保留现有 data 与 update。
- 完整回归另外发现 Windows 心跳读取期间瞬时拒绝原子替换，补齐有上限的重试，持续拒绝仍报错，旧文件保持完整且临时文件清除。
- 多链接测试补齐失败堆栈、隔离日志及显式UTF-8输出解码（避免Windows默认GBK解码掩盖异常）。单独5次及后续完整回归均通过，保留诊断用于后续复核，没有通过忽略断言掩盖问题。
